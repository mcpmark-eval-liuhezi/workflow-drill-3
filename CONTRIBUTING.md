# Contributing to workflow-drill

Thanks for contributing! The general process:

- Search for existing issues first to avoid duplicate work, and open an issue for anything you'd want help reviewing.
- Create a feature branch off `main` (e.g. `add-<topic>`), matching our standard branch-and-PR contribution workflow.
- Make a focused change, keeping commits small and descriptive.
- Open a pull request describing what changed and why; a maintainer review is required before merge.
- Address review feedback on the branch and restart review when the PR is updated.
